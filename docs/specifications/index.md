## Purpose

This folder contains human-readable behavior and interoperability specifications.

## Required documents

- Protocol principles
- Request manifest contract
- Output contract protocol
- Error semantics
- Capability contract
- Versioning and compatibility
- Negotiation behavior

## Required contract shape

Specifications must define inputs, outputs, errors, unsupported behavior,
capabilities, side effects, compatibility, validation, and evidence.

## Source-of-truth rule

Human-readable specifications define meaning. Corresponding schemas define
machine validation and must remain synchronized.

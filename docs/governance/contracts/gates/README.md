# Gate Contract Catalog

Status: active
Version: 1.0

## Purpose

This folder defines reusable gates and their pass conditions. The existing
SOP micro-gates remain the project-wide baseline.

## Gate groups

- Request readiness
- Intake and scope
- Authority and risk
- Baseline and dependency
- Execution
- Contract validation
- Behavioral verification
- Side-effect inspection
- Documentation synchronization
- Canonicalization
- Evidence and closure

## Gate requirement

Each gate must define its identifier, purpose, preconditions, action, pass
condition, evidence, owner, and failure behavior.

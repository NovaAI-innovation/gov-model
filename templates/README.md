# Reusable Templates

Status: active
Version: 1.0

## Purpose

This folder contains reusable, fillable instances of approved request,
contract, decision, evidence, release, and incident document types.

## Template rules

- Templates must match a registered document type.
- Required fields must remain visible.
- Safety-relevant values must not receive silent defaults.
- Placeholders must make incomplete requests detectable.
- Templates must declare their contract version.
- A template change requires review against its governing contract.

## Subfolders

- requests/ — request manifests
- outputs/ — output contracts
- decisions/ — decision records
- evidence/ — evidence records
- releases/ — release records
- incidents/ — incident reports
- governance/ — governance policies
- architecture/ — architecture contracts
- specifications/ — protocol and behavioral specifications
- phases/ — phase plans
